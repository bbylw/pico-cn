秉持对简洁的追求，Pico 提供了一个干净的起点，让你无需堆砌过多的 CSS 类和包裹层就能构建网站。

以下是我们「极致的极简主义」的故事。

Pico 起源于两个小小的不快：

> 「我可不想为了做一个只有标题、一段描述和一个小注册表单的落地页，就引入一个庞大的 CSS 框架。」— 一位沮丧的前端开发者

> 「我可不想为了添加一个简单的 `<input />`，就堆砌无意义的包裹层和一个个巨大的类名。」— 还是那位沮丧的前端开发者

这就是最初的想法。不妨称之为「极简主义史诗之旅」：

```html
<main>
  <h1>Join the pursuit of HTML simplicity</h1>
  <p>Let’s avoid meaningless div and classes and make it beautiful!</p>
  <form>
    <input type="email" placeholder="Your email" />
    <input type="submit">Let’s start!</input>
  </form>
</main>

<footer>
  This page should be fast enough to please Google's algorithm.
</footer>
```

仅此而已！我们相信在构建复杂网站时 CSS 类必不可少，但为什么要用类来处理默认样式？更重要的是，为什么要为了如此简单的结构而用 JavaScript 阻塞页面渲染？

在此基础上，我们添加了所有表单元素、HTML 地标、排版元素，以及我们能找到的一切相关标签。我们让每一个元素在浅色和深色模式下，默认就兼具响应式与优雅。

随着我们持续构建，社区不断壮大 🧡，随之而来的是一份责任：提供一套可靠的 CSS 重置，让人们面对我们的 HTML DOM 时不再感到难过。
