要在 Pico 中启用 RTL（Right-To-Left，从右到左），需要在 `<html>` 元素上设置 `dir="rtl"`。

```html
<!doctype html>
<html dir="rtl" lang="ar">
  ...
</html>
```

RTL 也可以按元素单独启用：
