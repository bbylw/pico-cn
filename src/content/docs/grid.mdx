<h2 id="about-css-grids">关于 CSS Grid</h2>

Pico 专注于原生 HTML 元素，因此我们保持这套栅格系统的极简。

一套完整的 flexbox 栅格系统——包含全部的排序、偏移和断点工具类——体积可能比整个 Pico 库还大，这并不符合 Pico 的精神。

如果你需要快速搭建原型或构建复杂布局，可以看看 **Flexbox 栅格布局**，例如 [Bootstrap Grid System](https://getbootstrap.com/docs/4.2/getting-started/contents/) 或 [Flexbox Grid](http://flexboxgrid.com/)。

如果你需要一个轻量且可定制的栅格，可以看看 **CSS Grid 生成器**，例如 [CSS Grid Generator](https://cssgrid-generator.netlify.app/)、[Layoutit!](http://grid.layoutit.com/) 或 [Griddy](https://griddy.io/)。

或者，你也可以[了解 CSS Grid](https://learncssgrid.com/)。
