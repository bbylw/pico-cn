<h2 id="pico-css-library">Pico CSS 库</h2>

为 Pico CSS 提供支撑的核心技术与资源。

- [Sass](https://sass-lang.com/)：CSS 预处理器
- [PostCSS](https://postcss.org/)：CSS 后处理器
- [Autoprefixer](https://www.npmjs.com/package/autoprefixer)：基于 [Can I Use](https://caniuse.com/) 的取值添加 CSS 厂商前缀
- [Clean CSS](https://www.npmjs.com/package/clean-css-cli)：CSS 优化与压缩工具
- [Sanitize.css](https://csstools.github.io/sanitize.css/)：跨浏览器默认样式
- [Normalize.css](https://necolas.github.io/normalize.css/)：CSS 重置
- [Tabler Icons](https://tabler.io/icons)：内置图标
- [jsDelivr](https://www.jsdelivr.com/package/npm/@picocss/pico)：CDN

<h2 id="website-and-docs">网站与文档</h2>

支撑我们网站与文档的技术栈。

- [Remix](https://remix.run/)：React 框架
- [Cloudflare](https://www.cloudflare.com/)：托管与网站 CDN
- [TypeIt](https://www.typeitjs.com/)：JavaScript 打字机效果
- [React Syntax Highlighter](https://github.com/react-syntax-highlighter/react-syntax-highlighter)
- [Theme toggles](https://toggles.dev/)：带动画的主题切换图标
- [CodeSandbox](https://codesandbox.io/)：示例云端开发平台
- [Figtree](https://www.erikdkennedy.com/projects/figtree.html)：用于标题的友好无衬线字体
- [Fira Code](https://github.com/tonsky/FiraCode)：带连字的等宽字体，用于代码片段
