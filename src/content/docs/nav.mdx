`<ul>` 会自动水平分布。

`<li>` 不带样式且内联排列。

`<a>` 仅在 `:hover` 时显示下划线。

<h2 id="link-variants">链接变体</h2>

你可以使用 `.secondary`、`.contrast` 和 `.outline` 类（[无类版本](/docs/classless/)中不可用）。

<h2 id="buttons">按钮</h2>

你可以在 `<li>` 内使用 `<button>`。

按钮的尺寸会自动匹配链接的大小与外边距。

<Ex
  html={`<article aria-label="Nav example" class="component"><nav><ul><li><strong>Acme Corp</strong></li></ul><ul><li><a data-discover="true" href="/docs/nav">About</a></li><li><a data-discover="true" href="/docs/nav">Services</a></li><li><button class="secondary">Products</button></li></ul></nav></article>`}
  code={`<nav>
  <ul>
    <li><strong>Acme Corp</strong></li>
  </ul>
  <ul>
    <li><a href="#">About</a></li>
    <li><a href="#">Services</a></li>
    <li><button class="secondary">Products</button></li>
  </ul>
</nav>`}
  lang="html"
  label="Nav example"
/>

<h2 id="dropdowns">下拉菜单</h2>

<h2 id="vertical-stacking">垂直堆叠</h2>

<h2 id="breadcrumb">面包屑</h2>

使用 `<nav aria-label="breadcrumb">`，可以把导航变成面包屑。

<Ex
  html={`<article aria-label="Breadcrumb example" class="component"><nav aria-label="breadcrumb"><ul><li><a data-discover="true" href="/docs/nav">Home</a></li><li><a data-discover="true" href="/docs/nav">Services</a></li><li>Design</li></ul></nav></article>`}
  code={`<nav aria-label="breadcrumb">
  <ul>
    <li><a href="#">Home</a></li>
    <li><a href="#">Services</a></li>
    <li>Design</li>
  </ul>
</nav>`}
  lang="html"
  label="Breadcrumb example"
/>

你可以通过局部 CSS 自定义属性 `--pico-nav-breadcrumb-divider` 更换分隔符。

<Ex
  html={`<article aria-label="Breadcrumb example" class="component"><nav aria-label="breadcrumb" style="--pico-nav-breadcrumb-divider:'✨'"><ul><li><a data-discover="true" href="/docs/nav">Home</a></li><li><a data-discover="true" href="/docs/nav">Services</a></li><li>Design</li></ul></nav></article>`}
  code={`<nav
  aria-label="breadcrumb"
  style="--pico-nav-breadcrumb-divider: '✨';"
>
  <ul>
    <li><a href="#">Home</a></li>
    <li><a href="#">Services</a></li>
    <li>Design</li>
  </ul>
</nav>`}
  lang="html"
  label="Breadcrumb example"
/>

<h2 id="overflow">溢出</h2>

`<nav>` 组件在容器上使用 `overflow: visible;`，并在子元素上使用负外边距，让链接在键盘导航下拥有美观的 `::focus-visible` 样式，同时保持内容水平对齐。

<Ex
  html={`<article aria-label="Overflow example" class="component"><nav aria-label="overflow"><ul><li><a data-discover="true" href="/docs/nav">About</a></li><li><a data-discover="true" href="/docs/nav">Services</a></li></ul><ul><li><a data-discover="true" href="/docs/nav">Products</a></li></ul></nav><nav aria-label="overflow-with-focus"><ul><li><a class="focused" data-discover="true" href="/docs/nav">About</a></li><li><a data-discover="true" href="/docs/nav">Services</a></li></ul><ul><li><a class="focused" data-discover="true" href="/docs/nav">Products</a></li></ul></nav></article>`}
  label="Overflow example"
/>
