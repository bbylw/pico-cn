<h2 id="name">名称</h2>

提及 Pico CSS 时，正确的品牌名称是「Pico CSS」。你也可以按个人偏好使用「Pico」或「Pico ✨」。

CSS 样式表可称为「pico.css」。但请避免使用「PicoCss」「PicoCSS」「Pico.css」或「pico」。

<h2 id="usage-agreement">使用协议</h2>

Pico CSS 的品牌名称与标志受知识产权法保护。

你可以将 Pico CSS 名称作为你的开源、非商业项目名称的一部分，例如「Pico-React」；但未经许可，不得在商业项目中使用该名称。

你不能在开源或闭源项目中使用 Pico CSS 的标志，但欢迎在文章或文档中使用，前提是注明出处。

在 T 恤、贴纸等周边商品上使用 Pico CSS 的品牌名称和标志，需要获得明确的书面许可。
