<h2 id="color">颜色输入框</h2>

`type="color"` 与其他输入类型保持一致的样式。

  type="color"
  value="#ff9500"

  label="Color input example"
/>

<h2 id="validation-states">验证状态</h2>

通过 `aria-invalid` 提供验证状态。

<Ex
  html={`<input aria-invalid="false" name="valid" placeholder="Valid" type="text" value="Valid"/><input aria-invalid="true" name="invalid" placeholder="Invalid" type="text" value="Invalid"/>`}
  code={`<input
  type="text"
  name="valid"
  value="Valid"
  aria-invalid="false"
>

<input
  type="text"
  name="invalid"
  value="Invalid"
  aria-invalid="true"
>`}
  lang="html"
  label="Validation states example"
/>

在表单元素下方用 `<small>` 定义的辅助文本，会继承验证状态的颜色。

<Ex
  html={`<input aria-describedby="valid-helper" aria-invalid="false" name="valid" placeholder="Valid" type="text" value="Valid"/><small id="valid-helper">Looks good!</small><input aria-describedby="invalid-helper" aria-invalid="true" name="invalid" placeholder="Invalid" type="text" value="Invalid"/><small id="invalid-helper">Please provide a valid value!</small>`}
  code={`<input
  type="text"
  name="valid"
  value="Valid"
  aria-invalid="false"
  aria-describedby="valid-helper"
>
<small id="valid-helper">Looks good!</small>

<input
  type="text"
  name="invalid"
  value="Invalid"
  aria-invalid="true"
  aria-describedby="invalid-helper"
>
<small id="invalid-helper">
  Please provide a valid value!
</small>`}
  lang="html"
  label="Validation states example"
/>
