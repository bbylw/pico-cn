<h2 id="indeterminate">不确定状态</h2>

将复选框的 `indeterminate` 属性设置为 `true`，即可让它呈现不确定状态。

<Ex
  html={`<label><input name="indeterminate" type="checkbox"/>Indeterminate</label>`}
  code={`<label>
  <input type="checkbox" id="indeterminate" name="indeterminate" />
  Indeterminate
</label>

<script>
  const checkbox = document.querySelector('#indeterminate');
  checkbox.indeterminate = true;
</script>`}
  lang="html"
  label="Indeterminate checkbox example"
/>

<h2 id="validation-states">验证状态</h2>

通过 `aria-invalid` 提供验证状态。

<Ex
  html={`<label><input aria-invalid="false" name="valid" type="checkbox"/>Valid</label><label><input aria-invalid="true" name="invalid" type="checkbox"/>Invalid</label>`}
  code={`<label>
  <input type="checkbox" name="valid" aria-invalid="false" />
  Valid
</label>

<label>
  <input type="checkbox" name="invalid" aria-invalid="true" />
  Invalid
</label>`}
  lang="html"
  label="Validation states example"
