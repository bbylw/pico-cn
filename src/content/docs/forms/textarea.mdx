<h2 id="validation-states">验证状态</h2>

通过 `aria-invalid` 提供验证状态。

<Ex
  html={`<textarea aria-invalid="false" name="valid" placeholder="Valid">Valid</textarea><textarea aria-invalid="true" name="invalid" placeholder="Invalid">Invalid</textarea>`}
  code={`<textarea name="valid" aria-invalid="false">
  Valid
</textarea>

<textarea name="invalid" aria-invalid="true">
  Invalid
</textarea> `}
  lang="html"
  label="Validation states example"
/>

在文本域下方用 `<small>` 定义的辅助文本，会继承验证状态的颜色。

<Ex
  html={`<textarea aria-describedby="valid-helper" aria-invalid="false" name="valid" placeholder="Valid">Valid</textarea><small id="valid-helper">Looks good!</small><textarea aria-describedby="invalid-helper" aria-invalid="true" name="invalid" placeholder="Invalid">Invalid</textarea><small id="invalid-helper">Please provide a valid value!</small>`}
  code={`<textarea
  name="valid"
  aria-invalid="false"
  aria-describedby="valid-helper"
>
  Valid
</textarea>
<small id="valid-helper">Looks good!</small>

<textarea
  name="invalid"
  aria-invalid="true"
  aria-describedby="invalid-helper"
>
  Invalid
</textarea>
<small id="invalid-helper">
  Please provide a valid value!
</small>`}
  lang="html"
  label="Validation states example"
/>
